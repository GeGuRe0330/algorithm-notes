# 기본 문법 주의점 (정수 나눗셈, 조건문 분기, return)

> 문법은 알아도 실수하기 쉬운, 코딩 테스트에서 실제로 걸렸던 지점들.

## 정수 나눗셈과 `%`

- 정수끼리 나누면 **소수점이 버려진다**. `3 / 2 == 1`, `4 / 3 == 1`.
- 그래서 `a / b == b / c`로 비율이 같은지 비교하면, 비율이 다른데도 같다고 나올 수 있다. (`4/3 == 3/2`가 둘 다 `1`)
  - 비교는 곱셈으로 바꿔서 한다: `a * c == b * b`.
- `0`으로 나누면 `ArithmeticException`이 난다. `a / b`, `a % b`를 쓰기 전에 `b`가 0일 수 있는지 본다.
- `%`는 나눈 나머지다. 한 바퀴 돌면 제자리로 오는 문제(각도, 시각, 요일)에 쓴다.
  - `(a + b) % 360`은 `a + b - (a + b) / 360 * 360`과 같다.
  - 자바의 `%`는 음수에서 음수가 나온다. `-10 % 360 == -10`

## `if` 여러 개 vs `if - else if`

- `if`를 따로 쓰면 **각각 독립적으로** 검사한다. 앞의 `if`가 참이어도 다음 `if`를 또 검사한다.
- 같은 변수를 바꾸는 `if`가 여러 개면 **뒤가 앞을 덮어쓸 수 있다.**
- "둘 중 하나만"이라는 뜻이면 `else if`로 잇거나, 각 분기에서 바로 `return`한다.

```java
if (A) { return x; }     // A가 참이면 여기서 끝난다
if (B) { return y; }     // A가 거짓일 때만 도달한다
```

## 메서드 끝의 `return`

- 반환형이 있는 메서드는 **모든 경로**가 값을 돌려줘야 한다. 그렇지 않으면 `missing return statement` 컴파일 에러가 난다.
- 문제가 "항상 둘 중 하나"라고 보장해도 컴파일러는 모른다.
  - 마지막 분기를 조건 없는 `else`로 쓰거나, 맨 끝에 대비용 `return`을 둔다.
