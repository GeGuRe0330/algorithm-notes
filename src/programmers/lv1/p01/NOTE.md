## 문제 요약

신호등 n개(2~5)가 각자 초록 → 노랑 → 빨강을 반복한다. 모든 신호등이 동시에 노랑인 가장 이른 시각을 구하고, 그런 시각이 없으면 -1을 반환한다. (시각은 1초부터 시작)

## 접근

1. 신호등 하나의 주기는 `G + Y + R`이다.
2. 시각 `t`에서 주기 안의 위치를 `r = (t - 1) % 주기`로 구한다 (0부터 시작).
   - `0 ≤ r < G` 초록, `G ≤ r < G + Y` 노랑, 나머지 빨강
3. `t = 1`부터 1씩 올리면서 모든 신호등이 노랑인지 확인하고, 처음 만족하는 `t`를 반환한다.
4. 상한은 `20^5 = 3,200,000`으로 잡았다. 주기가 최대 20, 신호등이 최대 5개라서 최소공배수가 이 값을 넘지 않고, 그 안에 없으면 이후에도 영원히 없다 → `-1`.

## 복잡도
- 시간: O(T × n) — T ≤ 3,200,000, n ≤ 5. 노랑이 아닌 신호등을 만나면 `break`해서 실제로는 더 빠르다.
- 공간: O(1)
