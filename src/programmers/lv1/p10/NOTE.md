## 문제 요약

문자열 배열 `seoul`(길이 1~1000)에서 `"Kim"`이 있는 위치(인덱스) `x`를 찾아서 `"김서방은 x에 있다"` 모양의 문자열을 반환한다. `"Kim"`은 배열에 딱 한 번 있고 반드시 있다.

## 접근

1. 배열을 앞에서부터 하나씩 보면서 `s.equals("Kim")`이면 그때의 인덱스를 저장하고 `break`한다. 인덱스는 `idx` 변수를 따로 두고 반복마다 1씩 올렸다.
2. 문자열은 `==`가 아니라 `equals`로 비교한다. 그래서 `"kim"`이나 `"Kimmy"` 같은 비슷한 문자열과 헷갈리지 않는다.
3. 반환 문자열은 `"김서방은 " + answer + "에 있다"`로 만든다. 띄어쓰기를 문제 그대로 맞춰야 한다.
4. 스트림의 `filter`로 풀어 보려 했으나, `filter`/`findFirst`는 값만 주고 인덱스를 주지 않아서 `for`가 더 단순했다. (`concepts/stream.md`의 "인덱스는 안 준다" 항목)
5. 다른 방법: `for (int i = 0; i < seoul.length; i++)`로 쓰면 `idx`를 따로 세지 않아도 된다. `Arrays.asList(seoul).indexOf("Kim")`으로 한 줄에 찾는 방법도 있다.
6. 직접 돌려 본 경계 입력(맨 앞, 길이 1, `kim`·`Kimmy` 같은 비슷한 이름이 섞인 경우)에서도 모두 정답이었다.

**풀이 중 생각 메모**
- 복잡하게 생각할 거 없이 그냥 for문으로 간단하게 해치워버리자
- Array.filter를 써보고싶었는데 오히려 더 어렵네....

## 복잡도
- 시간: O(N) — 최악에는 배열 끝까지 훑는다.
- 공간: O(1)
