# p14. 자연수 뒤집어 배열로 만들기

> 지문 원문은 옮기지 않고 내 말로 요약

## 문제 요약

자연수 `n`의 각 자리 숫자를 **거꾸로** 배열에 담아 반환한다. 예: 12345 → [5,4,3,2,1]. `n`은 10,000,000,000 이하.

## 접근

1. `String.valueOf(n)`으로 숫자를 문자열로 바꾼다. `n`은 `long`인 채로 넘기므로 `int` 범위(약 21억)를 넘는 값(최대 10,000,000,000)도 안전하다.
2. 자릿수는 `numStr.length()`로 미리 알 수 있으니 `ArrayList` 대신 그 길이의 `int[]`를 바로 만든다.
3. `i`번째 칸에 `numStr.charAt(길이 - i - 1) - '0'`을 넣는다. 뒤에서부터 읽어 거꾸로 쌓는 것이고, `'5' - '0'`은 `int` 5가 된다.
4. `10`, `100`처럼 끝자리가 `0`인 수는 한 글자씩 읽기 때문에 `[0,1]`, `[0,0,1]`처럼 `0`이 앞쪽에 정확히 들어간다.
5. 직접 돌려 본 입력: 예시 `12345`, 한 자리(`1`, `5`), `10`·`100`·`1000`, `120`, `1020304050`, `9876543210`, `10000000000`, `2147483647`·`2147483648`. `% 10`/`/ 10`으로 따로 구현한 기준값과 경계 12개·무작위 10만 개를 대조해 다른 결과 0개였다.
6. 다른 방법 (직접 써 보면 좋은 복습): `n % 10`을 꺼내고 `n /= 10`을 `n`이 0이 될 때까지 반복해 `List`에 모았다가 배열로 옮긴다. 이 방식은 이미 거꾸로 나오므로 뒤집기가 필요 없다.

**풀이 중 생각 메모**
- 일단 간단히 생각하면 long타입으로 주는 자연수 n은 사실상 숫자 하나하나가 의미가 있는거니까 String 문자열로 바꿔도 무방하겠는걸.
- 다만 고민인게 문제를 보면 10이나 100과 같은 숫자도 그냥 붙어서 오기 때문에, 단순히 숫자 하나하나만 떼어내서 만드는건 불가능해보여.
- 아 잘못생각했네? 그냥 숫자 하나를 배열에 넣는거니까 그냥 숫자 하나하나 읽어서 배열에 넣으면 되네~
- 길이가 변칙적이니 ArrayList가 훨씬 좋겠다. -> 아니다 그냥 길이만큼의 빈 배열을 만들어서 하나하나 넣으면 되겠다.
- 역순으로 해야하는거도 잊으면 안대! -> sort 생각해봤는데 이건 크기순이라 정갈해져. 그냥 역순으로 차근차근 쌓아야겠다.

## 복잡도
- 시간: O(L) — L은 자릿수(최대 11). 문자열 변환과 배열 채우기가 각각 한 번씩 훑는다.
- 공간: O(L) — 문자열과 결과 배열.
