## 문제 요약

메시지의 일부 구간(글자 위치 기준)이 스포 방지로 가려진다. 가려진 구간에 걸친 단어 중, 메시지 어디에서도 가려지지 않은 채 나온 적이 없는 단어를 "중요한 단어"라고 한다. 중요한 단어의 개수를 반환한다. (같은 단어는 한 번만 센다)

테스트는 4개 그룹이고, 그룹 1~3은 구간이 정확히 한 단어의 시작과 끝을 가리키는 제한이 있다.

## 접근

1. 메시지를 앞에서부터 훑으며 단어를 하나씩 완성하고, 각 단어의 `start`/`end` 위치를 기록한다. (스캔 변수 `i` 하나로 바깥·안쪽 반복을 이어서 사용)
2. 단어 `[start, end]`가 스포 구간 `[range[0], range[1]]`과 겹치는지 확인한다.
   - 겹치지 **않는** 경우: 단어가 구간보다 완전히 왼쪽(`end < range[0]`) 또는 완전히 오른쪽(`range[1] < start`)
   - 겹침 = 위 두 경우가 모두 아닐 때: `!(end < range[0] || range[1] < start)`
3. 가려졌으면 `hidden` 집합에, 아니면 `visible` 집합에 단어를 넣는다.
4. `hidden.removeAll(visible)`로 "가려진 적만 있는 단어"만 남기고 `size()`를 반환한다. 집합이라 같은 단어는 한 번만 센다.

## 복잡도
- 시간: O(L + W × R) — L: 메시지 길이, W: 단어 수, R: 구간 수. W ≤ 약 10,000, R ≤ 1,000이라 충분히 빠르다.
- 공간: O(L) — 두 집합에 담기는 단어 길이의 합

## 회고
- 문제 그룹 내 #3까지는 자력으로 품
- 처음엔 단순히 범위의 처음과 끝이 정확하다는 전제 하에 해당 단어를 통째로 문자열에 비교하는 식으로 접근함.
- 그룹4 에서는 구간이 단어 일부에 걸치는 경우 때문에 위치 기록 방식으로 변경.
- 중복 제거 + 존재 여부는 Set
