## 문제 요약

전화번호 문자열(길이 4~20)에서 **뒤 4자리만 남기고** 나머지를 전부 `*`로 바꾼 문자열을 반환한다.

## 접근

1. 남길 부분은 뒤 4자리, 가릴 부분은 그 앞이므로 `*` 개수는 `길이 - 4`.
2. `substring(길이 - 4)`로 뒤 4자리를 떼어 둔다.
3. `"*".repeat(길이 - 4)`로 별을 만들어 뒤 4자리 앞에 붙여 반환한다.
4. `replace`는 글자 값 기준이라 "위치로 앞부분만 바꾸기"에 맞지 않아 쓰지 않았다.
5. 길이가 4일 때는 `repeat(0)`이 빈 문자열이라 원본이 그대로 나온다. 길이 4~20 무작위 5만 개를 따로 구현한 방식과 대조해 다른 결과 0개였다.

**풀이 중 생각 메모**
- 전화번호 뒤에 네 자리만 빼고 나머지는 다 가리면 되는거네? replace를 쓰면 되겠다. -> 근데 이건 1:1 대응 비교를 해야하는데 사실상 불가능.
- 아니면 전화번호 뒤에 네 자리만 따로 빼서 새로 String을 만들까?
- 지금 해보는 방안으론 subString으로 뒷 네자리만 떼어놓고, 따로 별도 String 문자열을 만들어 리턴하는게 가장 효율적일거같은데?

## 복잡도
- 시간: O(L) — L은 전화번호 길이(최대 20). `repeat`와 `substring`, 이어 붙이기가 각각 길이에 비례한다.
- 공간: O(L) — 새로 만드는 결과 문자열.
