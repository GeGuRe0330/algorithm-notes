# p07. 제일 작은 수 제거하기

## 문제 요약

정수 배열(길이 1 이상, 서로 다른 값만 있음)이 주어지면 가장 작은 값 하나를 뺀 나머지를 원래 순서 그대로 담은 배열을 반환한다. 빼고 나서 비게 되면 `-1` 하나가 든 배열을 반환한다.

## 접근

1. 결과 길이는 원래 길이 − 1이다. 이 값이 `0`이면(원소가 하나뿐이면) 바로 `{-1}`을 반환한다.
2. 최솟값은 `Arrays.stream(arr).min().getAsInt()`로 구한다.
3. 원래 배열을 앞에서부터 한 번 훑으면서, 값이 최솟값이면 건너뛰고 나머지를 결과 배열에 `idx++`로 차례로 담는다. 순서가 그대로 유지된다.
4. 최솟값이 하나뿐(값이 모두 다름)이라는 제한사항이 있어서 "위치"가 아니라 "값"으로 건너뛰어도 된다. 같은 값이 여러 개였다면 틀렸을 방식이다.
5. 처음엔 길이가 유동적이라 `ArrayList`로 시작했으나, 반환형이 `int[]`라서 `Integer[]`에서 변환하는 과정이 번거로워 배열로 바꿨다. (결과 길이를 미리 알 수 있으므로 배열로 충분하다.)
6. 직접 돌려 본 경계 입력(최솟값이 맨 앞·맨 뒤·가운데, 길이 1·2, 음수와 `0`)에서도 모두 정답이었다.

**풀이 중 생각 메모**
- 이건 배열 길이가 유동적이니까 ArrayList로 연산을 수행하고 최종적으로 배열로 리턴시키는게 더 좋겠다.
- 해보니까 Integer[]로 변형해야하는데 int[]로 반환해야해서 오히려 귀찮네. 그냥 배열로 해야겠다.

## 복잡도
- 시간: O(N) — 최솟값 찾기 한 번, 복사 한 번.
- 공간: O(N) — 결과 배열.
