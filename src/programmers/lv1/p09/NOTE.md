## 문제 요약

길이가 1~100인 문자열 `s`가 주어지면 그 가운데 글자를 반환한다. 길이가 홀수면 가운데 한 글자, 짝수면 가운데 두 글자다.

## 접근

1. 길이가 짝수인지 홀수인지를 `s.length() % 2 == 0`으로 구별한다.
2. 홀수일 때 가운데 글자의 인덱스는 `length / 2`다. 정수 나눗셈이 소수점을 버려서 `5 / 2 == 2`가 가운데를 정확히 가리킨다.
3. 짝수일 때 가운데 두 글자는 인덱스 `length / 2 - 1`과 `length / 2`다. (`"qwer"`는 길이 4라 인덱스 1, 2)
4. `charAt(i)`는 `char`를 돌려주는데, `char` 두 개를 `+`로 더하면 글자가 이어지는 게 아니라 숫자 합이 된다(`'w' + 'e'`는 `236`). 그래서 `StringBuilder`에 하나씩 `append`해서 문자열로 만들었다.
5. 다른 방법: `substring(시작, 끝)`을 쓰면 한 글자와 두 글자를 같은 모양으로 쓸 수 있다. 시작은 `(length - 1) / 2`, 끝은 `length / 2 + 1`이다. (끝은 포함되지 않음)
6. 직접 돌려 본 경계 입력(길이 1~4, 길이 1~100 전체)에서도 모두 정답이었다.
