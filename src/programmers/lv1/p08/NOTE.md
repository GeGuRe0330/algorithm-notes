# p08. 없는 숫자 더하기

## 문제 요약

0~9 중 일부가 담긴 정수 배열(길이 1~9, 원소 중복 없음)이 주어진다. 배열에 **없는** 숫자들을 모두 찾아서 그 합을 반환한다.

## 접근

1. `0`부터 `9`까지 열 개를 담은 `ArrayList`를 만든다.
2. `numbers`의 숫자를 하나씩 보면서 `removeIf(num -> num == i)`로 리스트에서 같은 값을 지운다. 남은 값이 배열에 없는 숫자다.
3. 남은 값을 `stream().reduce(0, Integer::sum)`으로 더해서 반환한다.
4. 람다 안에서 쓰는 `i`는 `for-each`의 반복 변수라 반복마다 값이 한 번만 정해져서(effectively final) 컴파일 규칙에 맞는다.
5. 다른 방법 (직접 써 보면 좋은 복습):
   - `0`~`9`의 합은 `45`이므로 `45 − 배열의 합`이면 반복문 없이 구할 수 있다.
   - `boolean[10]`을 만들어 배열에 있는 숫자를 `true`로 표시하고, `false`인 인덱스만 더하는 방법도 있다.
6. 직접 돌려 본 경계 입력(길이 1인 `[0]`, `[9]`, 길이 9에서 `0`이나 `9` 하나만 빠진 경우, 순서가 섞인 경우)에서도 모두 정답이었다.

**풀이 중 생각 메모**
- 0 ~ 9까지 들어있는 ArrayList를 만들어서 들어있으면 해당 값을 0으로 만들고 sum 하면 되지 않을까?
- ArrayList도 필요 없이 그냥 배열만 있음 되겠네.

## 복잡도
- 시간: O(N × 10) — 숫자 N개마다 길이 10짜리 리스트에서 `removeIf`를 한다. 둘 다 최대 10 이하라 사실상 상수.
- 공간: O(1) — 길이 10짜리 리스트 하나.
