## 문제 요약

공백으로 구분된 정수들이 담긴 문자열 `s`에서 **최솟값과 최댓값**을 찾아 `"(최솟값) (최댓값)"` 형태의 문자열로 반환한다. 정수는 두 개 이상 들어 있고 음수도 나온다.

## 접근

1. 숫자가 공백으로 구분되어 있으므로 `s.split(" ")`으로 문자열 조각 배열을 만든다.
2. 조각은 아직 문자열이라 `Integer.parseInt`로 숫자로 바꿔 비교한다. 문자열 그대로 비교하면 `"9"`가 `"10"`보다 크게 나온다.
3. 초깃값은 `min = Integer.MAX_VALUE`, `max = Integer.MIN_VALUE`로 둔다. 모두 음수이거나 모두 양수여도 첫 값에서 바로 갱신되어 안전하다. `0`으로 시작하면 틀린다.
4. 배열을 한 번 돌며 더 작으면 `min`, 더 크면 `max`를 갱신하고, 마지막에 `min + " " + max`로 문자열을 만든다.
5. 직접 돌려 본 입력: 예시 3개, `"5 5"`, `"10 9 8"`, `"9 10"`, `"-9 -10"`, `"0 0 0"`, `"2147483647 -2147483648"`, `"2147483647 2147483647"`. 정렬해서 앞뒤를 꺼내는 방식으로 따로 구현한 기준값과 경계 15개·무작위 10만 개를 대조해 다른 결과 0개였다.
6. 다른 방법 (직접 써 보면 좋은 복습):
   - 반복마다 `parseInt`를 세 번 부르는 대신 `int n = Integer.parseInt(num);`으로 한 번만 하고 `n`을 비교한다.
   - `Math.min(min, n)`, `Math.max(max, n)`으로 `if`를 줄인다.
   - `Arrays.stream(s.split(" ")).mapToInt(Integer::parseInt)`로 `IntStream`을 만들어 `min()`/`max()`를 쓴다 (`concepts/stream.md` 참고).

**풀이 중 생각 메모**
- 공백으로 구분된 숫자가 저장되어있는 문자열
- 그 숫자 중 최소값과 최대값을 찾아 "[최소값] [최대값]" 형태의 문자열을 반환하는 함수를 완성하라.
- 공백으로 나뉘어져 있으니 split을 쓰면 되겠는걸?
- 최대값과 최소값을 구하는 메서드를 직접 구현할법도 하지만... 그냥 나눈 값을 배열로 저장해서 min과 max으로 구하면 더 편하고 빠를거같아.
- 그냥 뭐 ArrayList든 뭐든 다 필요없네 막상 짜보니

## 복잡도
- 시간: O(N) — N은 숫자 개수. 배열을 한 번 훑는다. (`split`과 `parseInt`도 문자열 길이에 비례한다.)
- 공간: O(N) — `split`이 만드는 문자열 배열.
