## 문제 요약

한 글자짜리 문자열들의 배열 `spell`(2~10개, 서로 중복 없음)과 단어 사전 `dic`(1~10개, 각 길이 1~10)이 주어진다. `spell`의 글자를 **각각 정확히 한 번씩** 모두 써서 만들 수 있는 단어가 `dic`에 있으면 `1`, 없으면 `2`를 반환한다. 글자를 빼거나 반복하거나 다른 글자를 섞으면 안 된다.

## 접근

1. 사전의 단어를 하나씩 꺼내서, `spell`의 글자가 그 단어에 들어 있는지 `word.contains(ch)`로 하나씩 확인하고, 들어 있는 글자 수를 `trueCount`에 센다.
2. `trueCount == spell.length`이면 `spell`의 글자가 모두 단어에 들어 있다는 뜻이다. 단어 하나를 마칠 때마다 `trueCount`를 0으로 되돌린다.
3. `contains`만으로는 "빠진 글자"만 걸러서, 남는 글자(`abc`)나 두 번 쓰인 글자(`aab`)를 가려내지 못한다. **단어 길이가 `spell.length`와 같은지** 조건을 하나 더 붙였다.
   - `spell`의 원소가 서로 다르다는 제한이 있으므로, 모든 글자를 갖고 있고 길이가 같으면 각 글자가 정확히 한 번씩만 쓰인 것이다.
4. 조건에 맞는 단어를 찾으면 `answer = 1`, 끝까지 못 찾으면 `2`를 반환한다.
5. 처음 풀이는 주어진 예시를 모두 통과했지만, 길이 조건이 없어서 `spell = {a, b}`, `dic = {"abc"}`, `{"aab"}`에서 `1`을 잘못 반환했다.
6. 다른 방법도 있다: 단어와 `spell`의 글자를 각각 정렬해 같은지 비교하면 길이와 글자 구성을 한 번에 확인할 수 있다.

## 복잡도
- 시간: O(D × S × L) — 사전 단어 수 D, `spell` 길이 S, 단어 길이 L(`contains`). 모두 최대 10이라 사실상 상수.
- 공간: O(1)
