## 문제 요약

주사위 4개(눈은 1~6)를 굴린 결과의 모양에 따라 점수를 계산한다. 모양은 5가지다: 4개가 같음, 3개가 같고 1개가 다름, 두 쌍이 각각 같음, 한 쌍만 같고 나머지 둘은 서로 다름, 모두 다름. 모양마다 점수 공식이 다르다(공식은 문제 페이지 참고).

## 접근

1. 눈 종류별로 몇 개 나왔는지 `diceArray[6]`에 센다. (`diceArray[눈 - 1]++`)
2. 가장 많이 나온 개수(`sameTimes`, 최댓값)로 먼저 큰 분기를 나눈다: `switch (sameTimes)`.
3. 개수 4 → 눈 하나로 바로 계산. 개수 3 → 개수가 3인 눈을 `p`, 1인 눈을 `q`로 잡는다. 개수 1 → 가장 작은 눈.
4. 개수 2는 두 경우로 갈린다.
   - 개수가 2인 눈이 둘이면 두 쌍 → `p`, `q`로 공식 계산.
   - 하나뿐이면 한 쌍 + 나머지 둘 → `p`를 뺀 나머지 두 눈의 곱(`filter`로 거르고 `reduce`로 곱함).
5. 처음 버전은 `sameIndex1/2` 두 변수를 훑는 순서에 의존해서 `1,1,1,4`처럼 외톨이 눈이 더 큰 경우에 틀렸다. 개수별로 변수를 따로 두는 방식으로 바꿔 순서와 무관하게 만들었다.
6. 람다 안에서 쓰는 `p`는 값이 바뀌는 변수라 컴파일 에러가 난다(effectively final 필요). 값을 `pair`에 복사해서 썼다.

**풀이 중 생각 메모**
- 이건 그냥 단순히 if문 분기만 잘해서 계산하면 될거같은데?
- 아 생각해보니, 어느 주사위가 같은지 구별하는 대목이 필요하네?
- 단순히 if문으로 조건을 다 나열하면 끝도없이 늘어나네. 애초에 처음부터 '몇개가 같은지'에 대한 구별이 필요하겠는걸?

## 복잡도
- 시간: O(1) — 주사위 4개, 눈 6종류로 입력 크기가 고정이다.
- 공간: O(1) — 길이 6짜리 배열 하나.
