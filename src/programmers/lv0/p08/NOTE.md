## 문제 요약

좌표 점 4개(0~100의 정수)가 주어진다. 점을 두 개씩 짝지어 직선 두 개를 만들었을 때, 두 직선이 평행한 짝짓기가 있으면 `1`, 없으면 `0`을 반환한다. 완전히 겹치는 경우도 평행으로 본다. 점은 서로 겹치지 않고, 어떤 직선도 x축·y축과 평행하지 않는다.

## 접근

1. 점을 `A=0, B=1, C=2, D=3`이라 하면 4개를 두 개씩 짝지어 직선 두 개를 만드는 방법은 **3가지**다: `AB-CD`, `AC-BD`, `AD-BC`. (점을 두 개 고르는 직선은 6개지만, 한 짝짓기에서 네 점이 한 번씩만 쓰이므로 비교는 3번이다.) 이 중 하나라도 평행이면 `1`.
2. 기울기는 점 하나의 `y / x`가 아니라 두 점 사이의 변화량 `(y2 - y1) / (x2 - x1)`이다.
3. 두 기울기가 같은지는 나눗셈 없이 **교차 곱셈**으로 비교한다: `dy1 / dx1 == dy2 / dx2` ⟺ `dy1 * dx2 == dy2 * dx1`. 자바의 정수 나눗셈은 소수점을 버려서 비교가 틀릴 수 있기 때문이다.
4. 같은 계산이 세 번 반복되므로 "점 번호 4개를 받아 평행인지 알려 주는" `isParallel` 메서드로 묶고, `solution`에서는 `||`로 세 번 호출한다.
5. 처음엔 `AB-CD` 한 가지만 검사해서, 주어진 예시 두 개는 통과해도 `AC-BD`나 `AD-BC`에서만 평행한 입력은 틀렸다. 호출 번호를 잘못 넣어 같은 직선끼리 비교하거나(`CD`와 `CD`), 점이 겹치는 짝(`BD`와 `AD`)을 비교하는 실수도 있었다. 점 세 개가 한 직선 위에 있는 입력에서 잘못된 짝이 `true`를 만들 수 있다.
6. 번호와 점 이름(`A, B, C, D`)을 오가면 헷갈리므로, 번호의 의미를 주석으로 적어 두면 좋다.

## 복잡도
- 시간: O(1) — 점 4개로 입력 크기가 고정이고, 비교는 3번(중복 호출까지 4번)이다.
- 공간: O(1)
