## 문제 요약

두 각도(각각 0~5000)를 더한 값을 구한다. 360도는 한 바퀴라 360의 배수는 같은 각으로 보므로, 결과는 0 이상 360 미만이어야 한다. 입력은 표준 입력으로 받고 결과를 출력하는 형식이다. 원래는 디버깅 유형이라, 주어진 식에서 빠진 `% 360`만 채우면 되는 문제였다.

## 접근

1. 두 각도의 합 `sum`을 구한다.
2. 합에서 360을 더 뺄 수 없을 때까지 뺀 값이 답이다. 이 값이 곧 `sum`을 360으로 나눈 나머지다.
3. 처음 풀이: `sum - (sum / 360) * 360`. 정수 나눗셈의 몫으로 "채운 바퀴 수"를 구해 그만큼 빼는 방식이다.
4. 같은 뜻의 한 줄 풀이: `(angle1 + angle2) % 360`. 의도가 바로 읽혀서 더 낫다.
5. 주의: 자바의 `%`는 음수에서 음수 결과가 나온다(`-10 % 360 == -10`). 이 문제는 입력이 0 이상이라 해당 없음.

## 복잡도
- 시간: O(1)
- 공간: O(1)
