# p06. 다음에 올 숫자

## 문제 요약

정수 배열(길이 3 이상 1000 미만)이 등차수열이거나 등비수열이다(항상 둘 중 하나, 등비의 공비는 0이 아닌 정수). 마지막 원소 다음에 올 숫자를 구해 반환한다.

## 접근

1. 앞의 세 원소로 수열의 종류를 판별한다. 등차면 `common[2] - common[1] == common[1] - common[0]`.
2. 등차면 `마지막 원소 + 공차`(`common[1] - common[0]`)를 반환한다.
3. 등차가 아니면 등비이므로 `마지막 원소 × 공비`(`common[1] / common[0]`)를 반환한다. 곱한 뒤 나누는 순서(`마지막 × common[1] / common[0]`)로 써서 공비가 정수일 때 정확히 떨어진다.
4. 처음엔 두 `if`가 서로 독립이라서, 등차로 구한 답을 등비 쪽이 덮어쓰는 경우가 있었다. 예: `{2,3,4}`. 정수 나눗셈이 소수점을 버려서(`4/3 == 3/2 == 1`) 등차수열도 "등비"로 판정됐다.
5. `{0,1,2}`처럼 등차수열에 0이 있으면 등비 조건의 `1 / 0`에서 `ArithmeticException`이 났다.
6. 각 분기에서 바로 `return`해서 위 두 문제를 모두 해결했다. 마지막 `return -1`은 컴파일러가 요구하는 대비용이며 실제로는 실행되지 않는다.

**풀이 중 생각 메모**
- 등차인지 등비인지 먼저 구별하는 로직이 필요해보이네.
- 등차, 등비 외에 다른 경우는 없다고 명시되어있으니 그냥 순차적으로 구별해봐도 무방하겠다.
- 주어지는 common 배열의 원소가 최소 3개니까 그냥 고정으로 1,2,3 번째 원소로 규칙을 구해도 되겠다.
- 그 후에 규칙에 맞게 다음 수를 계산해서 리턴하면 되는 식으로 접근해보자.

## 복잡도
- 시간: O(1) — 앞의 세 원소와 마지막 원소만 본다.
- 공간: O(1)
