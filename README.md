# algorithm-notes

코딩테스트 문제 풀이와 정리를 위한 레포. (Java / 프로그래머스)

## 구조

```
src/programmers/lv{0-5}/p{NN}/     # 레벨 안에서 01, 02, ... 순번
├── Solution.java   # 제출용 풀이
├── Main.java       # 로컬 실행용
└── NOTE.md         # 문제 요약, 접근, 복잡도, 회고
templates/          # 위 파일들의 템플릿
```

풀이 목록은 따로 두지 않는다. 폴더 구조와 각 `NOTE.md` 상단(문제번호, 난이도, 유형, 결과)을 참고.
